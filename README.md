# NexusEvents - Mini-Project: Full Stack Java Programming

This project implements a full-stack event management application (NexusEvents) with **Supabase** backend and is ready for **Netlify** deployment, as per the mini-project requirements.

## 🚀 Getting Started

I have built the entire frontend and UI structure for you. To make the backend and database functional, follow these simple steps to plug in your own Supabase credentials!

### 1. Set Up Supabase (Backend)
1. Go to [Supabase](https://supabase.com/) and create a free account.
2. Click **"New Project"** and give it a name (e.g., `NexusEvents`).
3. Once the project is created, scroll down to the **Project API** section to find your **Project URL** and **anon public key**.
4. Create a `.env` file in the root of the `nexusevents` folder with the following:
   ```env
   VITE_SUPABASE_URL=your-project-url
   VITE_SUPABASE_ANON_KEY=your-anon-key
   ```
5. **Database Setup:** Go to the "SQL Editor" in Supabase and run this query to create the events table:
   ```sql
   create table public.events (
     id bigint generated by default as identity primary key,
     title text not null,
     description text,
     start_date timestamp with time zone,
     location text,
     price integer default 0
   );
   
   -- Insert some mock data
   insert into public.events (title, description, start_date, location, price) values 
   ('Swap & Read', 'Book exchange cafe meetup', '2025-10-16 13:00:00+00', 'Book cafe', 100),
   ('Hack the Future', 'Technology venue hackathon', '2025-10-01 10:00:00+00', 'Tech Venue Hall 1', 1500);
   ```
6. **Authentication:** Go to Authentication -> Providers, and ensure **Email** provider is enabled.

### 2. Run the App Locally
```bash
cd nexusevents
npm run dev
```

### 3. Deploy to Netlify
1. Create a [GitHub](https://github.com/) repository and push this code to it.
2. Go to [Netlify](https://www.netlify.com/) and sign up.
3. Click **"Add new site"** -> **"Import an existing project"**.
4. Connect to your GitHub and select your repository.
5. Netlify will automatically detect Vite. Ensure the settings are:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
6. Click **"Deploy Site"**.
7. **Important:** Go to Site Settings -> Environment Variables in Netlify and add your `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.

That's it! Your assignment is fully implemented and deployed.
